# Animan 0.1.0 — Python engine + Vue desktop interface

This release resets the desktop release series to **0.1.0**, replacing the old
2.1.0 distribution. It includes the current Python engine and the compiled Vue
interface, source adapters, language preferences, proxy controls and resilient
video/subtitle downloads. No Python or Node.js installation is required.

| Platform | Archive | Validation |
| --- | --- | --- |
| Windows x64 | `Animan-v0.1.0-Windows-x64.zip` | Automated packaged backend/frontend/media checks |
| Linux x64 | `Animan-v0.1.0-Linux-x64.tar.gz` | Automated packaged backend/frontend/media checks; Ubuntu 22.04 build baseline |
| macOS Apple Silicon | `Animan-v0.1.0-macOS-arm64-UNTESTED.zip` | **UNTESTED on real Mac hardware**; CI package checks only |
| macOS Intel | `Animan-v0.1.0-macOS-x64-UNTESTED.zip` | **UNTESTED on real Mac hardware**; CI package checks only |

Extract the whole archive. On Windows run `Animan.exe`; on Linux run `./Animan`;
on macOS open `Animan.app`. The Vue interface opens in the native WebView where
available, with an installed-browser fallback. FFmpeg/ffprobe are included for
inspection, verification and subtitle muxing. Websites remain responsible for
their own availability and may require user-assisted verification.

**macOS packages are not Developer-ID signed or notarized.** Gatekeeper may block
them. No interactive Mac hardware testing is claimed. Linux compatibility depends
on system libraries; the tar archive is not a universal AppImage.

Each platform has a build-info JSON file. `SHA256SUMS.txt` covers all release assets.

Android is deliberately excluded from this release. The next milestone is a
signed Android package embedding the complete Python engine and Vue interface,
after native dependencies, background downloads and storage are validated.
