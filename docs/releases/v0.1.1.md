# AnimeLab 0.1.1 — responsive interface and persistent downloads

This update includes the Python engine and compiled Vue interface. Python and Node.js do not need to be installed separately.

- Mobile download cards retain readable titles and progress, with actions on a separate row. Global actions collapse into a compact menu, completed export locations are expandable, and the toolbar no longer covers the list.
- Settings have a mobile section selector, sources use compact cards, and extension filters fit small screens. Search and speed-limit dialogs remain usable in portrait and landscape.
- Safe-area spacing, touch targets and navigation adapt to small screens. English and French interfaces are covered by automated browser checks from 320 to 1440 pixels.
- Download preferences persist across server and container restarts. Docker includes persistent storage and graceful server shutdown.
- The application uses the AnimeLab name and selected violet/mint logo.

Extract the complete archive, then run `AnimeLab.exe`, `./AnimeLab` or `AnimeLab.app`. FFmpeg and ffprobe are included. The native WebView is used where available, with an installed-browser fallback.

macOS packages are **not Developer-ID signed or notarized**. Linux archives require compatible system libraries; they are not universal AppImages. Automated checks do not certify every desktop environment or external source. Each platform includes build provenance; `SHA256SUMS.txt` covers the release assets.

The matching Android build is published separately as **0.1.1 beta 1**.
